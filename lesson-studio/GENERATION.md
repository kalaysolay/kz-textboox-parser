# Генерация урока из готового учебника

В «Новый урок» выберите учебник и тему из списка. При наличии полного full_text программа берёт именно этот раздел parsed JSON: без повторного PDF/OCR и AI-парсинга. Заголовок урока можно уточнить, привязка к теме сохранится. Точное уникальное название темы, введённое вручную, тоже распознаётся без дополнительной модели.

Для «Только учебник»: локальная подготовка → автор RU/KK → независимый редактор. Это два отдельных запуска CLI; внутри каждого CLI может делать несколько запросов к модели для работы с файлами. Отдельного процесса планировщика нет. Для дополнительного источника добавляется исследователь; при нуле источников он не вызывается даже для записи пустого массива.

Если полного текста выбранной темы нет или разбор явно обрезан, программа использует существующие PDF-инструменты и локальный OCR как запасной путь, без отдельного AI-парсера. Готовый JSON можно использовать и без исходного PDF. Свободная тема без выбора раздела пока сохраняет прежний путь поиска материала — для прямой генерации выбирайте тему из списка.

## Качество и самопроверка

Автор и редактор получают один компактный снимок выбранного раздела: текст, определения, исходные задания, страницы и замечания к качеству. Снимок и исходный JSON привязаны к SHA-256. Другие главы и весь учебник перечитывать не требуется. OCR, пересказ и восстановленные таблицы оцениваются по смыслу, без требований посимвольного совпадения.

Содержательные правила лежат в prompts/fast-author.md и prompts/fast-review.md. Автор не добавляет фактов из памяти; непонятный материал нельзя дополнять догадками. Редактор отдельно проверяет ключевые факты, RU/KK и ответы на каждый вопрос по тому же источнику. Серьёзные замечания возвращаются автору один раз, после исправления снова работает отдельный редактор. Программные проверки отвечают за JSON, структуру, формулы, бюджет и связь ревью с текущим файлом. SHA-256 входа и окончательной редакции вычисляет сам сервер: модели не нужно запускать команды для хеша. Явно неподтверждённый редактором факт/ответ не может пройти с противоречащей ему меткой ready.

В первую очередь используются textbook_tasks этого раздела. Вопросы можно переводить, разделять и адаптировать без смены учебной цели. У question-блоков сохраняются sourceTaskId, sourcePages и answerBasis: по ним можно найти исходное задание и основание ответа. Если в учебнике нет готового ответа, автор составляет обоснованный ответ по его материалу, не приписывая его учебнику. Задание без достаточного материала или нужного изображения следует заменить другим. Открытые вопросы допускают несколько обоснованных ответов. При отсутствии структурированных заданий используются вопросы из full_text либо явно помеченная адаптация по конкретному фрагменту.

## Логи и время

В каталоге урока сохраняются:

- 00-Заказ.json — параметры и закреплённый CLI/модель;
- 01-Источник учебника.json — снимок фактически использованного текста и заданий;
- Дополнительные источники.json — [] при запрете внешних источников;
- главный .lesson.json, Проверка.json, 04-Ревью.json;
- Журнал.jsonl — фактические этапы, безопасные события инструментов, длительности, хеши и число заданий;
- logs/author.md, logs/reviewer.md — краткие фактические действия и ограничения ролей, без скрытых рассуждений.

Карточка показывает «Генерация всего» отдельно от «Текущий/Последний этап». Общее время включает подготовку и все попытки текущей схемы, но не паузу между остановкой и продолжением. Новые заказы содержат сохранённый список этапов. Старые заказы остаются совместимы с прежними пятью этапами; неизвестное общее время для них не выдумывается.

Настройка CLI и любой доступной ему модели — в [AI_CONFIGURATION.md](AI_CONFIGURATION.md). В окне нового урока можно включить «Переопределить для этого урока»: это одноразовый выбор CLI/модели поверх конфига, который не изменяет сам файл. Профилей и автоматической подмены модели нет. Конфиг влияет на новые заказы, продолжение сохраняет первоначальный выбор.

[Результаты реальных тестов и границы замера](docs/FAST_GENERATION_2026-10-29.md).

Повторная генерация с тем же названием не создаёт новую редакцию: существующий каталог защищён, показывается сообщение об ошибке. Для незавершённого заказа используйте «Продолжить»; для отдельного варианта задайте другое название.
