Настройте один из CLI по [инструкции](../AI_CONFIGURATION.md), откройте «Новый урок», выберите указанный учебник/раздел, короткий объём и один дополнительный источник. Для сравнения создавайте отдельный заказ после изменения конфига: продолжение закреплено за первоначальной моделью. Проверьте пять этапов, источники и обе версии во вкладках «Чтение»/«Проверки», затем экспорт HTML. Для проверки восстановления остановите исследование, перезапустите сервер и продолжите заказ: источник должен остаться завершённым.

Новая автоматическая проверка цитат применяется к теме из каталога с известным смещением и пригодным текстовым слоем PDF, до 32 страниц. Старый свободный ввод темы сохраняет прежний поиск источника; OCR и неподтверждённая карта страниц требуют отдельной работы. Проверка цитат подтверждает соответствие тексту, а не историческую истинность. Один успешный урок не гарантирует качество других предметов или моделей.
