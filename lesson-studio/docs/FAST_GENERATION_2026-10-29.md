# Прямая генерация из JSON — приёмка 29 октября 2026

## Выполнено

Для новых заказов с выбранным разделом готовый full_text используется напрямую. Локальная подготовка сохраняет один компактный снимок раздела и исходных заданий; отдельного AI-парсера и планировщика нет. При внешних источниках=0 исследователь вообще не запускается. Автор и независимый редактор используют модель из ai.config.json. Старые заказы и их продолжение сохраняют прежний маршрут.

Содержательные правила вынесены в prompts/fast-author.md и prompts/fast-review.md. Перефразирование и восстановление таблиц допустимы; редактор проверяет факты по выбранному материалу и каждый ответ по исходному заданию. Вопросы сохраняют sourceTaskId, sourcePages, answerBasis. Открытые вопросы предполагают обоснованный пример ответа, а не единственное мнение; нельзя восполнять отсутствующий в учебнике ответ новыми фактами.

В Журнал.jsonl сервер записывает этапы, действия, длительности и хеши, включая происхождение входа и число исходных заданий. Роли сохраняют короткие фактические logs/author.md и logs/reviewer.md. Скрытые рассуждения и сырые потоки CLI не сохраняются. В интерфейсе общее время отделено от времени последнего этапа.

## Автотесты и совместимость

node --test test/*.test.mjs tests/*.test.mjs из lesson-studio: **100 прошли, 0 ошибок, 0 пропусков**. Проверены два AI-этапа для готового JSON даже без PDF; отсутствие чужих заданий в снимке; дополнительный исследователь только при включённых источниках; исправление после отрицательного ревью; продолжение без повторного автора/подготовки; запасная локальная PDF-подготовка для отсутствующего/обрезанного текста; общее время и паузы; непротиворечивость ready с явно неподтверждёнными фактами/ответами. Прежние тесты обоих CLI, фиксации модели, пятиэтапных старых заказов, редактора и экспорта также прошли.

Ограничение: свободная тема без выбора раздела сохраняет старый путь поиска; для прямой генерации выберите тему из списка. Внешний веб-поиск и качество других моделей в этих замерах не оценивались. Никаких ограничений списка моделей, профилей или автоматической подмены нет.

SHA-256 финального файла в новой схеме вычисляет сервер, а не модель: входной хеш передаётся редактору, после завершения его работы отчёт привязывается к фактическим байтам и сохраняет reviewInputSha256/hashBoundBy. Это убирает команды для хеша и повторные попытки экранирования путей. Правка файла после завершения по-прежнему делает старое ревью неактуальным. Два дополнительных регрессионных теста проверяют серверную привязку и мелкие правки редактора.

Дополнительная языковая приёмка завершена. Первый адресный повтор GLM занял 562,058 с и исправил глагол/падежи, но оставил неудачный перевод «спица». Итоговые структура, происхождение вопросов, отчёт по каждому ответу, хеш и оба HTML-экспорта повторно проверены — PASS. Это не заменяет профессиональную языковую редактуру при публикации.
