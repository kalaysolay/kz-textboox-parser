# Мастерская уроков

Выбор Codex/OpenCode, модели и уровня рассуждений через `ai.config.json`: [Настройка CLI и модели](AI_CONFIGURATION.md). [Результаты тестов обоих инструментов](docs/AI_RUNTIME_TESTS_2026-10-28.md). [Полная генерация по PDF и найденные ограничения](docs/LESSON_E2E_2026-10-28.md).

План, текущий шаг, обнаруженные проблемы, решения с обоснованием и результаты проверок: [Журнал разработки](docs/Журнал%20разработки.md).

Что фактически поддержано и проверено, включая ограничения: [Матрица совместимости](docs/Матрица%20совместимости.md).

Полноценное локальное веб-приложение для пакетов `lessons/<класс> класс/<предмет>/<название>/*.lesson.json`. Работает с реальными файлами: библиотека, поиск и фильтры, чтение на русском и казахском, структурированный редактор, источники, проверки и журнал. Изображения в пилотных уроках не создаются.

## Запуск

Требуется Node.js 20+ и pnpm. Из каталога `lesson-studio`:

```powershell
pnpm install
pnpm start
```

Откройте **http://127.0.0.1:4317**. Сервер слушает только loopback. Другой порт: `$env:LESSON_STUDIO_PORT=4318; pnpm start`.

Сборка не требуется. Используется KaTeX **0.16.11**, закреплённый в lockfile и соответствующий исследованной версии Дамулаб. JavaScript, CSS и шрифты KaTeX загружаются локально. Внешние ссылки и YouTube требуют интернета.

## Настройки агентов

В окне «Новый урок по учебнику» выбираются объём и источники. По умолчанию: короткая лекция (ориентир 450, максимум 650 слов на каждом языке), учебник и не более одного полезного внешнего источника. Доступны обычный (700/950) и подробный (1000/1300) режимы, а также только учебник. Выбор запоминается в этом браузере и фиксируется в новом заказе; существующие уроки и заказы не меняются.

Все роли получают ограничения. Программная проверка считает слова в блоках каждой локализации, включая списки, таблицы, вопросы и ответы, и число внешних источников. Превышение не позволяет принять урок даже при положительном ревью: он возвращается автору на одно исправление, затем требует внимания редактора. Редактор отдельно проверяет повторы и воду. Числовой лимит не гарантирует качество объяснения.

## Работа

- Библиотека читает папку `../lessons` при запросе, без индексной базы. Для нового агентского пакета обновите страницу.
- «Чтение» переключает RU/KK, ширину компьютера/телефона (до 390 px) и два режима. «Как в Damulab» использует общий рендерер сайта и выбран по умолчанию; «Мастерская» показывает редакторское представление со связями блоков и источников. На телефоне содержимое адаптируется к доступной ширине.
- «Редактор» меняет обе языковые версии, метаданные, блоки, порядок и связи с источниками. Для каждого блока доступны происхождение и существующие `sourceRefs`. Неизвестные поля документа сохраняются. Таблицы и числовые проверки редактируются как JSON в своих полях. Некорректный JSON подсвечивается.
- «Источники» показывает исходные сведения и фактический список файлов пакета с размером и SHA-256. Файлы можно скачать.
- «Проверки» вызывает `validateLesson` из общего `core.mjs`: структура, паритет, KaTeX и перечисленные точные числовые вычисления. Это не подтверждение педагогического качества или полной фактической точности. Ревью действительно только при точном совпадении `04-Ревью.json.lessonSha256` с байтами `.lesson.json` и вердикте `ready_for_preview`.
- «Журнал» показывает реальные записи `Журнал.jsonl`, включая локальные сохранения.
- «Экспорт» скачивает **сохранённую** редакцию JSON или отдельный HTML RU/KK. HTML сохраняет исходники формул, их режим, цели, типы выделений и пары вопрос/ответ. Название передаётся в metadata импорта и не повторяется вторым H1 в контенте.

Изменения не публикуются автоматически. «+ Новый урок» запускает пять отдельных процессов выбранного CLI: извлечение учебника, дополнительные источники, план, автор и независимый редактор. Вкладка «В Damulab» подключает административный сеанс, готовит конкретную загрузку, отправляет черновик и сравнивает сохранённые RU/KK. Публикация выполняется отдельным действием после актуального независимого ревью.

## Генерация через локальный CLI

Поддерживаются Codex CLI и OpenCode CLI 2. Без `ai.config.json` сохраняется Codex с моделью из локальных настроек. Для явного выбора CLI и модели скопируйте `ai.config.example.json` в `ai.config.json` и настройте его по [инструкции](AI_CONFIGURATION.md). Один выбор действует для всех пяти этапов и сохраняется в заказе; изменение конфига влияет на новые уроки. Авторизация остаётся в выбранном CLI, отдельный API-ключ Мастерская не запрашивает. Путь можно задать в поле `executable`; прежняя переменная `LESSON_STUDIO_CODEX_EXE` также поддерживается для Codex.

В «+ Новый урок» выберите учебник и тему из его оглавления либо задайте свою. Каталог строится по книжным JSON из `parsed_outputs`, читает метаданные с учётом BOM и связывает PDF по `source.file_name`, явным связям реестра или прежних заказов. Старые версии одного PDF и служебные JSON не дублируют книги. PDF из `sources` остаётся источником для проверки страниц; при отсутствии привязки книга видна, но запуск остановлен.

Тема берётся из `topics_with_pages` (включая обнаруженные вложенные уроки); титульные/служебные разделы отфильтрованы. Выбранные ID, страницы, язык заголовка и признак оценённого конца диапазона сохраняются в `00-Заказ.json.textbookTopic`. Название можно уточнить. Предмет и класс подставляются автоматически; ручное название предмета на казахском нужно только для неизвестного справочнику предмета. Наличие разбора не означает, что OCR или факты уже приняты редактором.

Каждый этап читает свои скиллы и входные файлы, пишет артефакты в человекочитаемый каталог урока. Исследователь использует поиск; учебник остаётся основой. Изображения автоматически не генерируются. Исходники и отчёты сохраняются рядом с `.lesson.json`.

Один запуск выполняется за раз. Завершённый этап фиксируется хешем; при сбое следующий запуск продолжает с последнего проверенного результата. Кнопка «Остановить» останавливает принадлежащее запуску дерево процессов. После перезапуска сервера незавершённый запуск помечается прерванным. Состояния находятся в `.local/jobs/`, события этапов — в `Журнал.jsonl` урока. Стенограммы модели и скрытые рассуждения не сохраняются.

Лимиты и доступность выбранного CLI и поставщика распространяются и на эти процессы. После исчерпания лимита восстановите доступ и нажмите «Продолжить»: используется сохранённый выбор заказа. Если вручную изменён уже подтверждённый артефакт, автоматическое продолжение блокируется до новой проверки. После одного адресного исправления с повторным независимым ревью оставшиеся серьёзные замечания переводят запуск в «требует внимания».

## Загрузка с локального компьютера

1. Сохраните и проверьте урок, откройте «В Damulab» и подключитесь к нужному адресу с учётной записью администратора. Для удалённого адреса требуется HTTPS; HTTP разрешён только на loopback.
2. Выберите существующие предмет, класс и тему. Класс обязан совпасть с уроком. Темы создаются в админке сайта. Выберите теорию с самопроверками либо итоговый тест AUTO; для AUTO нужны опубликованные вопросы темы.
3. Нажмите «Проверить загрузку», проверьте адрес, названия и тему, затем «Загрузить черновик». Передаются сохранённые HTML RU/KK и реальные байты assets. Сервер создаёт или обновляет урок по стабильному `externalId`.
4. Мастерская считывает результат обратно и сравнивает текст, форматирование, формулы и их режим, таблицы, списки, картинки, видео и семантические блоки. При расхождении публикация блокируется, причина записывается в журнал. Откройте ссылки на серверный просмотр и редактор для визуальной проверки.
5. После актуального независимого ревью доступна отдельная кнопка публикации. Подтверждение показывает конкретный урок и адрес сайта. Повторная загрузка той же редакции не создаёт дубликат; правка в админке останавливает автоматическую перезапись.

Пароль, cookies и CSRF живут только в памяти процесса; после остановки сервера нужен повторный вход. Сопоставление локальной и серверной редакций хранится в `<урок>/.local/damulab/`, резервные серверные ответы — в `.local/remote-revisions/`. Не удаляйте сопоставление: существующий неизвестный `externalId` намеренно блокирует перезапись. Для восстановления сначала сравните серверную версию; автоматического принятия конфликтующих изменений нет.

Целевой Damulab обязан поддерживать studio API 1.0, пакет v2, условную запись и тот же renderer 2.0.1. Если поддержки нет, приложение останавливается до загрузки. Порядок выпуска сервера и проверки на проде: [Инструкция выпуска](docs/Выпуск%20и%20эксплуатация.md).

Точный подготовленный состав, изоляция изменений переводчика и результаты проверки кандидатов: [состав выпуска от 23 октября](docs/Состав%20выпуска%20—%202026-10-23.md). `node prepare-release.mjs` создаёт снимок локальных файлов в новом `.local/release-*` с хешами; это overlay существующего репозитория с учебниками. OCR-кэш, node_modules, сеансы и серверные сопоставления исключаются.

Следующий рабочий этап — [приёмка на соответствующем проду тесте](docs/План%20приёмки%20на%20тесте.md): качество генерации и переноса, админка и настоящий портал ученика. Подготовленный кандидат и локальный PASS не означают готовность к проду; переход возможен только после приёмки и отдельного решения пользователя.

Первый аудит в настоящей админке 22 октября 2026 года выявил потери заголовков таблиц, типов списков и блочного режима формул после открытия и сохранения в Quill. [Исходный отчёт](docs/Проверка%20отображения%20в%20Damulab%20—%202026-10-22.md).

В ветке `feat/lesson-studio-damulab-compatibility` исправлены эти потери, добавлены семантические блоки и общий предпросмотр. Содержимое двух пилотных уроков проверено после сохранения в локальном Damulab обеих локализаций. [Результат второго этапа и границы проверки](docs/Предпросмотр%20и%20блоки%20—%202026-10-23.md). Это соответствие локальному Damulab из той же ветки; изменения не развёрнуты на рабочем сайте.

## Общий рендерер

Редактируемый источник: `dlab/src/main/resources/static/js/lecture-content.js`, `css/lecture-content.css` и локальные шрифты сайта. Мастерская хранит точную автономную копию в `public/damulab/` и `public/fonts/`; Spring не требуется для её запуска. Манифест фиксирует SHA-256 каждого файла.

После изменения источника выполните из `lesson-studio`:

```powershell
pnpm sync:damulab
pnpm check:damulab
pnpm test
```

По умолчанию ожидается соседний каталог `../../dlab`. Другое расположение задаётся через `DAMULAB_REPO_DIR`. При наличии checkout обычные тесты также обнаруживают рассинхронизацию; без него Мастерская использует сохранённую копию.

Предпросмотр показывает **текущие несохранённые правки**. Он изолирован iframe с CSP и sandbox на отдельном loopback-origin: дополнительный порт выбирается автоматически. Этот сервер выдаёт только собранные документы по случайным временным адресам и не имеет файлового API. Такой origin нужен вложенному YouTube; `srcdoc` с opaque origin блокировал его Cache Storage. Ссылка «Открыть предпросмотр отдельно» открывает тот же временный документ; в нём проверены видео и fullscreen, включая телефонную ширину. Автоматизация клика плеера через два вложенных iframe пока недоступна; этот конкретный путь требует ручной проверки. Камера и микрофон приложению не нужны.

Камера, микрофон и захват экрана явно запрещены заголовком `Permissions-Policy` на обоих адресах предпросмотра; обычное воспроизведение от этих разрешений не зависит.

Шапка сайта, личный прогресс и контрольные тесты Damulab здесь не воспроизводятся. Предпросмотр не заменяет проверку цикла сохранения в Quill и проверку медиа. Технический пакет с существующим значком приложения и роликом из официального примера YouTube находится в `fixtures/media`, отдельно от учебных `lessons`.

## Сохранение

Клиент передаёт SHA-256 открытого файла в `If-Match`. Сервер отклоняет устаревшую редакцию с HTTP 409 и не перезаписывает более свежую правку. Повторные запросы к одному уроку сериализуются. Перед заменой файла выполняется повторная сверка хеша; замена — запись во временный файл и `rename` в том же каталоге.

Перед сохранением проходит техническая проверка. Прежние точные байты сохраняются в `<каталог урока>/.local/revisions/`. Новая редакция получает `revision + 1` и `status: draft`. В `Журнал.jsonl` записываются время, предыдущий и новый SHA-256. Старый отчёт редактора не изменяется: интерфейс показывает, что он устарел.

Это локальный однопользовательский инструмент. Проверка хеша защищает обычные одновременные правки и действия приложения, но не является межпроцессной файловой блокировкой для произвольного внешнего редактора. Не редактируйте основной файл другим процессом в момент сохранения.

## API

Все пути определяются инвентаризацией `lessons`; клиент не передаёт произвольные абсолютные пути. Каталоги-симлинки в инвентаризации пропускаются, чтение за пределами корня запрещено. Источники-учебники по абсолютным путям не раздаются. Защита Host/Origin ограничивает использование приложения своим локальным origin.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/lessons` | Библиотека |
| GET | `/api/lessons/:id` | Документ, хеш, проверка, ревью, файлы, журнал |
| PUT | `/api/lessons/:id` | `{doc}`, обязательный `If-Match` |
| POST | `/api/render` | `{doc,lang}`, безопасный HTML с KaTeX |
| POST | `/api/render` | `{doc,lang,mode:"damulab",token}` → `document`, `previewUrl` на отдельном локальном origin |
| GET | `/api/lessons/:id/preview?lang=ru` | Отдельный просмотр сохранённой редакции общим рендерером |
| POST | `/api/validate` | `{doc}`, результат проверки |
| GET | `/api/lessons/:id/export?format=json` | Канонический документ |
| GET | `/api/lessons/:id/export?format=html&lang=ru` | Производный HTML |
| GET | `/api/lessons/:id/artifact?name=...` | Файл из списка пакета |
| GET | `/api/lessons/:id/assets/:assetId` | Только растровый файл из manifest assets |
| GET / POST | `/api/generation` | Только задачи с активностью и временем сервера / новый запуск |
| GET | `/api/generation/catalog` | Учебники и CLI, один раз при открытии формы |
| POST | `/api/generation/:id/resume` или `/stop` | Продолжить или остановить запуск |
| GET | `/api/damulab` | Состояние подключения без секретов |
| POST | `/api/damulab/connect` или `/disconnect` | Подключить / завершить сеанс |
| GET | `/api/damulab/catalog?subjectId=…&gradeId=…` | Предметы, классы и темы выбранной пары |
| GET | `/api/lessons/:id/damulab` | Сопоставление редакции с сервером |
| POST | `/api/lessons/:id/damulab/prepare` | Подготовить отправку, срок 10 минут |
| POST | `/api/lessons/:id/damulab/upload` | Отправить по planId и сверить результат |
| POST | `/api/lessons/:id/damulab/publish` | Опубликовать проверенный lessonSha256 |

## Проверки разработки

```powershell
pnpm test
pnpm check:lessons
```

Интеграционные серверные тесты поднимают временные пакеты на случайном loopback-порту и закрывают процессы. Они проверяют сохранение и резервные редакции, устаревшие и одновременные запросы, привязку ревью, безопасное отображение, экспорт, ограничения путей, Host/Origin и размер входных данных. `tests/core.test.mjs` проверяет общий формат и математику. Визуальная проверка браузера и реальных мобильных устройств выполняется отдельно.

## Прогресс генерации

Карточка показывает действие, время текущего (после остановки — последнего) этапа и последнюю активность агента. Статусы запрашиваются раз в 4 секунды без обхода каталога и запуска проверки CLI; таймер на экране обновляется раз в секунду. События CLI превращаются в фиксированные подписи: чтение страниц, поиск темы, инструмент, запись файлов. Тексты команд, вывод инструментов и рассуждения не сохраняются и не показываются. Сведения об активности сохраняются с ограничением частоты записи.

Через 2 минуты без событий появляется «Давно нет событий». Существование процесса показано отдельно и не гарантирует полезный прогресс. Долгое действие не объявляется зависанием и не останавливается автоматически. При потере связи карточки остаются с предупреждением, что данные устарели. У старых запусков нет точных таймеров этапов; последняя активность берётся из последнего подтверждённого результата, если он есть.
