**Дата обработки:** 2026-05-09  

---

## 1. Текстовый слой PDF

Инструмент: `tools/pdf-extract/extract-pdfjs.mjs` → `ocr/ocr_text_kaz_tili_dauletkereeva_4grade_part1_probe`.

- Страниц: **128**.
- По выборке страниц текстовый контент ограничен водяным знаком **OKULYK** (как у учебников без выделяемого слоя). Полноценного извлечения уроков без OCR нет.

## 2. OCR (правило skill → каталог под `ocr/`)

- Скрипт: `tools/pdf-extract/ocr-pdfjs.mjs` (**pdfjs-dist** + **@napi-rs/canvas**, **tesseract.js**, языки **`kaz+rus`**, масштаб рендера **2**, диапазон **`all`**).
- Выход PNG+TXT по страницам: `ocr/ocr_pages_kaz_tili_dauletkereeva_4grade_part1/`.
- Предупреждения Helvetica от pdfjs при рендере — ожидаемый шум.

---

## 3. Структура и метаданные

- Из титула/выходных данных OCR: **«Алматыкітап баспасы», 2019**, **авторлар** Н.Ж. Даулеткереева, Г.Б. Мухангалиева, **128 бет**, **часть 1**.
- **ISBN** по OCR на стр. колофона не восстановлены полностью (обрезанный текст вида приказа МОН) → в JSON **`isbn`** оставлен `null` с пояснением.

## 4. Оглавление (МАЗМҰНЫ)

Стр. **126–127**: номера страниц зашумлены OCR; список **48 тем** восстановлен вручную по якорям в текстах уроков (заголовки сабақтар), с перекрёстной сверкой оглавления.

Участки **повышенной неопределённости**:

- заголовки **15-го** сабақа (различие между OCR «Шегарашы» и педагогическим смыслом «шебер/мақсат»);
- заголовок **29-го** сабақа: OCR «Менің қалауым» vs формулировка в оглавлениях родственных изданий «Менің қаладағы үйім» — в теме указаны оба варианта с пометкой.

## 6. Качественный итог

- **Высокая уверенность:** год издания, издатель, объём книги в листах, общая нумерация сабақтар (~48), логический каркас бөлімдері (Отан / құндылықтар / мәдени мұра), отдельные устойчивые тапсырмалар (мыс.: бет 69 грамматика, бет 96 «Сиқырлы кілем» заголовгі).
- **Средняя уверенность:** МАЗМҰНЫ; орфографиялық сөздік 124–125 (көзқараспен теріп қолмен тексеру керек); дословті verbatim фрагменттер — қысқа режимдегі циталар.
- **Низкая уверенность:** жекелеген сабақ атауының формулярлары; **`topic_rule_links`** — программалык топтастырулық бағыт (басыламадағы нақты қайта дәлделу үшін).

**Практикалық келесі қадам:** МАЗМҰНЫның басыладым үлгісінен `page_start` қайта санақтау немесе сынықты беттер үшін қарсы қойылған PDF (немесе қайта OCR сапасын жоғарылату).
