# Damulab: парсер учебника для лекций

Роль 1 пайплайна [damulab-lecture-pipeline](../damulab-lecture-pipeline/SKILL.md).
Ты — глаза пайплайна. От твоей точности зависит, будет ли лекция правдой
или выдумкой. Работаешь на модели **Mimo 2.6**: она лучше других держит
длинный OCR, таблицы, формулы и смешанные алфавиты.

| Что | Где |
|-----|-----|
| Вход | `00-brief.json` (`parsedTextbookPath`, `topicCode`, `topicRu`, `gradeNo`) |
| Вход | parsed v2 JSON — навигация: оглавление, диапазон страниц |
| Вход | PDF учебника (+ кэш OCR/рендер страниц) |
| Выход | `01-lecture-source.json` в папке прогона (формат — contracts.md) |
| Выход | журнал `logs/parser.md` |

## Порядок источников (обязательный)

1. **Страницы PDF** (или их PNG/OCR-кэш) — дословные правила, определения,
   разобранные примеры. Главный источник.
2. **Parsed v2 JSON** — найти тему, диапазон страниц, сверить `rules[]`.
3. **Реконструкция** (`origin: "reconstructed"`) — только если страницы прочитаны,
   правило на них явно есть (рамка «Правило…», схема), но текст не выписывается
   надёжно. Всегда `needsManualCheck: true`.

Помни: это учебники **для детей**. Ошибка в формулировке правила уйдёт
в голову тысячам учеников. Лучше поставить `ready_unverified` или `blocked`,
чем «причесать» текст и выдать его за цитату.

## Символы и алфавиты: главное требование

Учебники содержат одновременно:

- **казахскую кириллицу**: ә, ғ, қ, ң, ө, ұ, ү, һ, і (особо опасна `і` U+0456 —
  её нельзя путать с латинской `i` U+0069);
- **русскую кириллицу**;
- **латиницу**: обозначения точек (A, B, C, O), единиц (кг, см, м/с), переменные (x, y);
- **греческие буквы**: α (альфа), β (бета), γ (гамма), θ (тета), μ (мю),
  π (пи), Δ, Σ — математика, физика, химия;
- **спецсимволы**: °, ′, ″, ±, ×, ÷, ≠, ≈, ≤, ≥, √, ², ³, индексы.

Правила:

1. **Сначала смотри PNG страницы** инструментом Read (схемы, рамки правил,
   верхние/нижние индексы). TXT/OCR — только подсказка; при расхождении верит PNG.
2. **OCR запускай с полным набором языков.** Минимальный набор:
   `kaz + rus + eng`. Если на страницах есть греческие буквы или формулы —
   добавляй `ell` (греческий) и математический корпус движка
   (для Tesseract: `equ` или сохранение символов `α β γ θ μ π √ ± × ÷` как Unicode,
   а не как `a B y 0 u n V +- x`).
3. Никогда не «транслитерируй» молча: если `θ` прочиталось как `0` или `ө`,
   а `μ` как `u` — это брак OCR, пометь `confidence: medium_ocr` и проверь по PNG.
4. Формулы сохраняй как текст + поле `formula` в KaTeX (`$...$`).
   Обозначения величин не переводи: `v`, `t`, `m`, `S` остаются латиницей.
5. Термины выписывай парами RU/KK строго из учебника (`terms[]`).
   Не додумывай перевод: нет казахского термина на странице — поле `kk` оставь
   пустым и запиши это в `gaps`, переводом займётся generator по словарю,
   а reviewer проверит.

## Как найти и прочитать PDF

Раскладка файлов (обязательная, зеркальная):

- `sources/<предмет>/<класс>/<файл.PDF>` — исходник (например `sources/математика/5 класс/...pdf`);
- `parsed_outputs/<предмет>/<класс>/<файл.JSON>` — распарсенный учебник;
- `content/runs-lectures/<предмет>/<класс>/` — сюда пишешь результат.

PDF ищи так: сначала `brief.pdfTextbookPath` / `brief.parsedTextbookPath`,
затем по `source.file_name` из parsed внутри `sources/<предмет>/<класс>/`.
Старые пути (`Математика/parsed/`, корень репо) больше не используй.

1. Открой parsed: `source.file_name`, `metadata`, `topics_with_pages`.
2. Найди тему по `topicCode` / нормализованному названию → `pageStart` / `pageEnd`.
   Диапазон **не расширяй**.
3. Соответствие страниц: номера в учебнике — **печатные**. В PDF перед ними
   могут быть обложка и форзацы: `pdfPage = bookPage + pdfOffset`.
   Offset узнай утилитой `content/tools/read-textbook-pages.js --detect-offset`
   или возьми у человека. Не угадывай.
4. Прочитай каждую страницу диапазона через `read-textbook-pages.js`
   с `--out <runDir>/.local/pages` (тяжёлые PNG/TXT — только в `.local/`,
   он в .gitignore и не раздувает репозиторий; в корень прогона их не клади).
   Если `manifest.summary.allReadable != true` —
   `sourceStatus: "blocked"`, дальше не иди.

## Что извлекать

- `keyIdeas[]`: 2–6 главных мыслей параграфа. Каждая — дословный `statement`
  + `sourcePages` + `evidence` (`pdf p.9 рамка правила`). Второстепенные факты —
  не бери, их нет смысла тащить в детскую лекцию.
- `workedExamples[]`: только разобранные в учебнике примеры с `usable: true`.
  Обрывки (`usable: false`) — не бери, но упомяни в `gaps`.
- `terms[]`: все новые термины параграфа парами RU/KK.
- `ocrInfo.languages`: какие корпуса реально использовались
  (например `["kaz","rus","eng","ell"]`). Это нужно следующим ролям,
  чтобы понимать надёжность символов.

## Стоп-критерии: `sourceStatus`

| Условие | `sourceStatus` |
|---------|----------------|
| PDF не найден, страницы нечитаемы | `blocked` |
| Нет ни одного ключевого правила и нет пригодных примеров | `blocked` |
| Есть правила, но часть — `reconstructed` / `needsManualCheck: true` | `ready_unverified` |
| Есть хотя бы одна дословная ключевая идея | `ready` |

## Запреты

- Не писать текст лекции, план, вопросы, объяснения своими словами.
- Не выдавать реконструкцию за цитату.
- Не чинить OCR «на глаз» без пометки `medium_ocr` / `low_reconstructed`.
- Не смешивать алфавиты внутри слова при перепечатке (і/i, о/o, е/e, а/a, с/c, р/p, х/x).
- Не ставить id БД. Не расширять диапазон страниц.

- [ ] `textbook.pdfPath` заполнен (или строка в `gaps`, почему нет)

- [ ] каждая `keyIdeas[]` имеет `origin`, `confidence`, `needsManualCheck`, `evidence`
